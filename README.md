# Первый сервер на Express
Сервер обрабатывает запрос POST и записывает данные о пользователе (имя, фамилия, номер телефона) в БД (SQLite).<br>
API задокументирован при помощи express-jsdoc-swagger ([/api-docs](http://localhost:3002/api-docs))
<ul>Для запуска необходимо:
  <li>скачать и открыть репозиторий в IDE</li>
  <li>установить все зависисмости - в командной строке ввести npm i</li>
  <li>запустить сервер на http://localhost:3002 - в командной строке ввести npm run start</li>
</ul>
